# Raw Datasets

## Overview

This directory contains the original datasets collected for the Global Healthcare Performance & Equity Analysis graduation project.

## Purpose

These datasets serve as the raw source files for the project's data preparation, cleaning, integration, and analysis stages.

## Data Handling Rules

* Original source files must remain unchanged.
* Data cleaning must be performed on separate working copies.
* Missing values must not be replaced with zero without methodological justification.
* Every dataset must retain its source information and relevant documentation.
* Cleaned datasets and notebooks must be stored in their designated task directories.

## Contents

The directory will contain 14 original datasets covering population demographics, economic conditions, education, healthcare workforce and capacity, healthcare coverage, health expenditure, and financial protection.
