## Overview

This folder contains the financial hardship and healthcare equity analysis conducted as part of Phase 2.

The analysis investigates financial hardship across wealth quintiles and explores its relationships with Universal Health Coverage (UHC), out-of-pocket health expenditure, and economic development.

* `Financial_Hardship_Total_Pct`
* `Large_Spending_Pct`
* `Impoverishing_Spending_Pct`
* `Q1_Poorest_Pct`
* `Q2_Pct`
* `Q3_Pct`
* `Q4_Pct`
* `Q5_Richest_Pct`
* `Equity_Gap_Pct_Points`
