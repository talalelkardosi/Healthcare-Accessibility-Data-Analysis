# Socioeconomic & Education Analysis

**Project:** Global Healthcare Performance & Equity Analysis
**Phase:** Phase 2 – Data Analysis
**Task:** Task 02 – Socioeconomic & Education Analysis
**Analyst:** Aya Nasr

## Overview

This folder contains the socioeconomic and education analysis conducted as part of Phase 2.

The analysis explores the relationships between economic development, educational indicators, and Universal Health Coverage (UHC) across countries and over time.

## Indicators Analyzed

* `GDP_Per_Capita_PPP_2021`
* `Secondary_Enrollment_Gross_Pct`
* `Adult_Literacy_Rate`
* `UHC_Service_Coverage_Index`

## Deliverables

* `socioeconomic_analysis.ipynb` — Complete analysis and visualizations.
* `socioeconomic_analysis_summary.csv` — Statistical summary and key findings.
* `socioeconomic_analysis_report.md` — Analysis report.
* `charts/` — Generated charts and visualizations.
