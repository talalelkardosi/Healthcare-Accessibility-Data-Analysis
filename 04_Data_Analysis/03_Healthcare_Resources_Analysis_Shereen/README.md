# Healthcare Resources Analysis

**Project:** Global Healthcare Performance & Equity Analysis
**Phase:** Phase 2 – Data Analysis
**Task:** Task 03 – Healthcare Resources Analysis
**Analyst:** Shereen

## Overview

This folder contains the healthcare resources analysis conducted as part of Phase 2.

The analysis explores the availability and distribution of healthcare resources across countries and examines their relationships with Universal Health Coverage (UHC).

## Indicators Analyzed

* `Doctors_Total`
* `Doctors_Per_10k`
* `Nurses_Midwives_Per_10k`
* `Hospital_Beds_Per_10k`
* `UHC_Service_Coverage_Index`

## Deliverables

* `healthcare_resources_analysis.ipynb` — Complete analysis and visualizations.
* `healthcare_resources_analysis_report.md` — Analysis report and key findings.
* `healthcare_resources_analysis_summary.csv` — Descriptive statistical summary.
* `healthcare_resources_comparison_2018.csv` — Country comparison for 2018.
* `healthcare_resources_correlation_summary.csv` — Correlation results.
* `healthcare_resources_trends.csv` — Time-series summary.
