# Healthcare Coverage & Financing Analysis

**Project:** Global Healthcare Performance & Equity Analysis
**Phase:** Phase 2 – Data Analysis
**Task:** Task 04 – Coverage & Financing Analysis
**Analyst:** Hassan Mostafa

## Overview

This folder contains the analysis of Universal Health Coverage (UHC), healthcare expenditure, and out-of-pocket spending across countries and over time.

The analysis examines the relationships between healthcare financing indicators and UHC, using pooled observations, country-level comparisons, and a 2023 cross-sectional analysis.

## Indicators Analyzed

* `UHC_Service_Coverage_Index`
* `Health_Exp_Per_Capita_PPP`
* `Health_Exp_Pct_GDP`
* `OOP_Pct_Current_Health_Exp`
