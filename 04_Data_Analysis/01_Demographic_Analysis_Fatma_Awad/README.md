# Demographic Analysis

**Project:** Global Healthcare Performance & Equity Analysis
**Phase:** Phase 2 – Data Analysis
**Task:** Task 01 – Demographic Analysis
**Analyst:** Fatma Awad

## Overview

This folder contains the demographic analysis conducted as part of Phase 2 of the project.

The analysis explores population size, age structure, urbanization trends, and their relationships with Universal Health Coverage (UHC).

## Deliverables

* `demographic_analysis.ipynb` — Complete analysis and visualizations.
* `demographic_analysis_summary.csv` — Statistical summary and key findings.
* `demographic_analysis_report.md` — Final analysis report.
* `charts/` — All generated charts and visualizations.

## Source Dataset

`03_Integrated_Datasets/integrated_healthcare_dataset.csv`

The original integrated dataset is used as read-only input and is not modified.
