## Scope

Prepare and validate the population and demographic indicators required for the healthcare accessibility analysis.

## Indicators

* Population
* Population aged 0–14 (%)
* Population aged 65+ (%)
* Urban population (%)

## Deliverables

* `demographics_clean.csv` — Cleaned dataset
* `demographics_cleaning.ipynb` — Reproducible cleaning notebook
* `cleaning_log.txt` — Cleaning steps, validation results, and documented issues

## Data Standards

* Country identification uses ISO3 codes from the project Country Dictionary.
* The primary key is `ISO3 + Year`.
* Missing values remain missing; no zero-filling or interpolation.
* Raw source files remain unchanged.
* The dataset is reviewed before final project integration.
