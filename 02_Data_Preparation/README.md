# Data Preparation & Cleaning

## Overview

This directory contains the cleaned datasets, reproducible notebooks, and cleaning logs produced during Phase 1 of the Global Healthcare Performance & Equity Analysis graduation project.

## Phase Objective

Prepare, clean, validate, and document all datasets before integrating them into the final analytical dataset.

## Task Structure

| Task                                 | Responsible Member   | Main Scope                                   |
| ------------------------------------ | -------------------- | -------------------------------------------- |
| 01 — Population & Demographics       | Fatma Awad           | Population and demographic indicators        |
| 02 — Economy & Education             | Assigned Team Member | Economic and education indicators            |
| 03 — Healthcare Workforce & Capacity | Assigned Team Member | Doctors, nurses, and hospital beds           |
| 04 — Healthcare Coverage & Financing | Assigned Team Member | Healthcare coverage and expenditure          |
| 05 — Financial Hardship & Equity     | Assigned Team Member | Financial hardship and wealth-related equity |

## Standard Deliverables

Each task folder should contain:

* Cleaned dataset (`.csv`)
* Reproducible cleaning notebook (`.ipynb`)
* Cleaning log (`cleaning_log.txt`)

## Data Standards

* Use ISO3 and Year as the primary merge key where applicable.
* Preserve missing values; do not replace missing values with zero.
* Do not interpolate values unless explicitly approved by the project lead.
* Keep raw source datasets unchanged.
* Document cleaning decisions, validation results, and data limitations.
