## Scope

Prepare and validate population and demographic indicators required for the Global Healthcare Performance & Equity Analysis project.

## Indicators

* Population
* Population aged 0–14 (%)
* Population aged 65+ (%)
* Urban population (%)

## Deliverables

* `demographics_clean.csv` — Cleaned dataset
* `demographics_cleaning.ipynb` — Reproducible cleaning notebook
* `cleaning_log.txt` — Cleaning steps, validation results, and documented issues

## Data Standards

* Country identification uses ISO3 codes.
* The primary key is `ISO3 + Year`.
* Missing values remain missing; no zero-filling or interpolation.
* Raw source datasets remain unchanged.
* The dataset requires final review before project integration.
